# Integrated-contract acceptance

This is the engineering closure checklist created by Decisions 0021 and 0022.

## Stamina

- [ ] Wind and Reserve are separate authoritative values.
- [ ] Move effort is separated from Wind debit and Reserve load.
- [ ] Recovery depends on observable action state.
- [ ] Reserve does not regenerate meaningfully during an active round.
- [ ] Between-round recovery is declared and versioned.
- [ ] Acute Wind participates directly in immediate vulnerability.
- [ ] Reserve initially affects vulnerability indirectly, preventing double counting.
- [ ] Work rate and stamina bands are measured under observable CPU policy.

## Integrated contract

- [ ] Existing N/Q/R/S/O unit pins remain frozen.
- [ ] A new integrated schema and marker stream exist.
- [ ] RNG is partitioned into stable named substreams.
- [ ] The same authoritative runtime drives commandlet and live arena.
- [ ] Pause, speed, rendering, and camera do not alter the stream.
- [ ] Range, evasion, policy, stamina, condition, knockdown, count, ruleset, scoring, and verdict coexist in one run.
- [ ] Stoppage and decision paths both execute validly.
- [ ] First divergent event is reported when a pin moves.

## Product evidence

- [ ] The Director can open the arena and run the integrated bout.
- [ ] A spectator can explain the decisive exchange from replay evidence.
- [ ] One thin impact/crowd/commentary/humor/silence package is reviewed.

Completion requires implementation evidence, not only checked boxes in prose.
