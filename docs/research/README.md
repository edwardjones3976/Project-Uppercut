# Research lanes

Six narrow collections rather than "all boxing research". Each is meant to reach
ten to twenty strong sources and stop, because a collection nobody can read is a
collection nobody uses.

| Lane | Document | State |
|---|---|---|
| Punch biomechanics and contact quality | `punch_biomechanics.md` | **7 sources, 6 read** |
| Fatigue, pacing and recovery | not yet collected | — |
| Knockdowns, concussion, balance and referee stoppage | not yet collected | — |
| Boxing tactics, defensive structures and Ringcraft | not yet collected | — |
| Fighting-game responsiveness, determinism and rollback | not yet collected | — |
| Training, feedback, spectator comprehension and accessible controls | not yet collected | — |

The pipeline, the evidence gate and the access rules are described in
`research/README.md`. The one-line version: **discovery is free, and canon costs
a Decision record.** No source in any lane is currently accepted into canon, and
a test asserts that so it cannot become true quietly.

A lane document says three things and is worth reading in this order: what the
collection **supports**, what it explicitly **does not support**, and the **open
questions** it should answer next. The second of those is the one that keeps a
research folder honest — a pile of citations that only ever agrees with the game
is a pile that was gathered to agree with it.
